# Hide — Leather Supply Landing Page

A static landing page for **Hide**, a (fictional) leather supplier for independent crafters and small brands. Built with plain HTML, CSS, and vanilla JS — no build step required.

## Preview

Open [`index.html`](index.html) directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

```
hide-landing-page/
├── index.html
├── assets/
│   ├── css/styles.css
│   ├── js/main.js
│   └── images/
└── README.md
```

## Deploying to GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repo settings, enable **Pages** and point it at the `main` branch, root directory.
3. The site will be published at `https://<username>.github.io/<repo>/`.

Copy, product names, and contact details are placeholders for demonstration purposes.
